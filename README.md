# vk01-knob

用 VK-01（ANTICATER_MINI）旋钮，在 Mac 上给 Claude 桌面版、Codex（GPT）和豆包做**审批确认**，并用旋钮灯显示工作状态。

## 功能

- **单击旋钮**：批准当前模式应用里正在等待的审批（Allow / 允许一次 等）。没有待审批时什么都不做。
- **双击旋钮**：在 Claude → GPT → 豆包 之间切换；最前面是哪个应用，会自动切到哪个模式。
- **选择卡**：出现单选 / 多选卡片时，转旋钮移动绿框，按一下选中；多选卡转到最后一格 Submit 再按提交。
- **旋钮灯**：工作中闪烁 RGB，待审批常亮绿，空闲时灭（用旋钮会闪多彩）。
- **菜单栏**：只显示对应应用的图标，右下角一个状态点（灰 空闲 / 橙·蓝·紫 工作中 / 绿 待审批）。

## 文件

- `init.lua`：Hammerspoon 配置（放到 `~/.hammerspoon/init.lua`）。
- `vk01.py`：通过 USB 给旋钮写按键映射和灯效的脚本（放到 `~/anticater_debug/vk01.py`）。

## 使用

1. 安装 [Hammerspoon](https://www.hammerspoon.org/) 并在系统设置里授予「辅助功能」权限。
2. 旋钮用 USB 连接（灯效写入只走 USB，蓝牙无效）。先把按下键映射成 F13：`python3 vk01.py f13`。
3. 复制 `init.lua` 到 `~/.hammerspoon/`，在菜单栏点「重新加载配置」。

## 注意

- 只会按白名单里的按钮（Allow、Allow once、允许一次、批准、确认 等），不会按「始终允许」「拒绝」。
- 不同应用的界面文字可能随版本或语言变化，如果认不出按钮，查看 Hammerspoon 控制台日志里的「按钮变化」。
- 旋钮底层协议（USB VID 0x514C / PID 0x8850）是实测得到的，仅适用于该型号。
